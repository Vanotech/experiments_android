# Experiments
Experimental app to explore various Android concepts and technologies.

* Android app architecture
* Android app modularization
* CameraX
* Coil
* Compose
* Koin (previously Hilt)
* Kotlin Multiplatform (initial work only)
* Kotlinx Serialization (previously Moshi)
* Ktor (previously Retrofit)
* Navigation3
* Paging3
* Room
